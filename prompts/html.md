# Запит для створення HTML-каталогу книжок
```text
Створи один файл books.html — адаптивну сторінку-каталог книжок.

Вимоги:

- Використовуй лише HTML і CSS: жодного JavaScript, фреймворків або зовнішніх бібліотек.
- Усі стилі розмісти всередині тегу <style>.
- Дані нижче впиши безпосередньо в HTML, не завантажуй JSON окремо.
- Покажи кожну книжку окремою карткою: жанр, назва, автор, опис і рік видання.
- Додай заголовок «Книжкова полиця» та короткий підзаголовок.
- Зроби охайний сучасний дизайн: світлий фон, картки з округленими кутами й легкими тінями.
- Розміщуй картки адаптивною сіткою, щоб сторінка добре виглядала на телефоні й комп’ютері.
- Додай коректну HTML-структуру, українську мову документа та meta viewport.
- Створи повний вміст файла books.html одним блоком коду.
- Дані для книг візьми з books.json
```

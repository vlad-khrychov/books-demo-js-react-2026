# Запит для створення файла з книжками

```text
Згенеруй 10 вигаданих книжок для навчального каталогу та створи файл books.json.

Для кожної книжки вкажи:
- id — унікальне ціле число від 1 до 10;
- title — назву українською;
- author — вигадане ім'я автора українською;
- year — рік видання від 2015 до 2025;
- genre — жанр українською;
- description — короткий опис сюжету українською, одне речення.

Збережи всі 10 книжок у файлі books.json як коректний JSON такого формату:
{
  "books": [
    {
      "id": 1,
      "title": "Назва книжки",
      "author": "Ім'я Прізвище",
      "year": 2024,
      "genre": "Жанр",
      "description": "Короткий опис сюжету одним реченням."
    }
  ]
}

Створи файл у робочій папці. Не додавай до файла Markdown, коментарі чи пояснення.
```

# Запит для створення простого JSON-сервера

Скопіюй цей запит у нову сесію:

```text
Створи простий окремий HTTP-сервер на Node.js для навчального прикладу.

Вимоги:
- Використовуй лише вбудовані модулі Node.js, без npm-пакетів і фреймворків.
- Сервер має читати дані з локального файла books.json, який лежить поруч із server.js. У файлі є об'єкт із масивом книжок у властивості books.
- На GET-запит до http://localhost:3000/api/books повертай вміст books.json у форматі JSON.
- Налаштуй CORS, щоб сторінка, відкрита з іншого порту або джерела, могла робити запит до сервера. Дозволь методи GET і OPTIONS та повертай успішну порожню відповідь на OPTIONS preflight-запит.
- Для невідомого маршруту або методу повертай статус 404 і JSON з описом помилки.
- Не обслуговуй HTML, CSS чи JavaScript-файли — це окремий API-сервер.
- Збережи реалізацію простою й зрозумілою для новачка.
```
